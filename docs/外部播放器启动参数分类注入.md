# 外部播放器启动参数：分类注入

「启动参数」默认在每次播放时都注入。分类注入让同一份参数模板只在命中指定影片分类时附加，例如只给动漫开启 Anime4K 超分，真人电影仍然按原样播放。

本功能依据影视库元数据判定分类，元数据缺失时自动不生效，不影响播放本身。

## 一、开关位置与含义

入口：「设置 → 播放 → 外部播放器 → 启动参数」下方的四个开关。

| 开关   | 默认  | 注入条件                |
| ---- | --- | ------------------- |
| 全部注入 | 开启  | 每次播放都注入，不判断影片类型与元数据 |
| 动漫注入 | 关闭  | 影视库元数据中的类型包含动画类条目   |
| 电影注入 | 关闭  | 影视库元数据中的作品类型为电影     |
| 剧集注入 | 关闭  | 影视库元数据中的作品类型为剧集     |

- 三个分类开关之间是「或」关系，可以同时开启。
- 「全部注入」开启时，另外三个开关变灰不可操作；**它们的值会保留**，关掉「全部注入」后恢复原选择。
- 「全部注入」和三个分类开关全部关闭时，只有媒体地址、外挂字幕与续播这类必需参数生效，等价于关闭附加参数。
- 判定发生在播放进程启动时：切集、换季、列表内跳转都沿用本次起播的判定；修改开关后需要重新起播。

## 二、分类是怎么判定的

判定来源是影视库已刮削的作品元数据，而不是文件名或目录名：

- **电影／剧集**：作品类型 `movie` / `tv`。ISO、BDMV 与普通视频共用同一份作品元数据。
- **动漫**：作品的类型（genres）中出现以下任一名称——`Animation`、`Anime`、`动画`、`动画片`、`動畫`、`動畫片`、`アニメ`、`アニメーション`、`애니메이션`。判定忽略大小写与首尾空格，四种元数据语言都能命中。
- 名称匹配同时兼容 TMDB（字符串数组）、Jellyfin／Emby 与本地 NFO（`{name: ...}` 对象数组）三种元数据形态。

需要注意：

- 西式动画（如皮克斯作品）同样带 `Animation` 类型，因此也会命中「动漫注入」。
- 元数据缺失以下情况都算「无元数据」，分类不命中：资源不在影视库、目录未建库或未刮削、作品未匹配到条目。此时仅「全部注入」开启时才会注入。
- 影视库元数据类型名称随刮削时使用的元数据语言保存，但上述名称集合已覆盖四种语言，切换语言后无需重新刮削。

## 三、生效范围

| 播放方式                                             | 是否按分类注入      |
| ------------------------------------------------ | ------------ |
| 普通视频与 STRM（文件夹浏览、影视库、媒体中心续播、自定义播放列表、隐式播放列表、自动切季） | 是            |
| WebDAV ISO／BDMV（标题模式与蓝光菜单）                       | 是            |
| 本地 ISO／BDMV（菜单或主标题）                              | 是            |
| 音乐／音频会话                                          | 否，始终使用完整启动参数 |

## 四、关键规则：占位符行始终注入

含 `{url}`、`{subfile}`、`{start}` 占位符的参数行承载媒体地址、外挂字幕与单集续播，**不受分类开关影响**。分类不命中时被去掉的只是纯附加参数行，例如：

```text
--glsl-shaders=~~/shaders/Anime4K/Anime4K_Clamp_Highlights.glsl
```

这也是为什么默认模板 `--sub-file={subfile}`、`{url}`、`--start={start}` 在关闭「全部注入」后依然能正常播放、加载字幕和续播。

## 五、参数写法约定

- 每行一个参数，行首行尾空白会被忽略，空行自动跳过。
- 行内连续空白会压缩为一个空格，等号后的整段值仍是同一个参数。
- 除三个占位符外，不要在其他参数值里写花括号：含未知花括号的词会被当成残留占位符整行移除。
- 软件会在你的参数之后追加自己托管的参数（全屏、IPC 管道、播放列表、字幕与音轨脚本、缓存策略等）。同名选项以后追加的为准，因此这些行为不能用启动参数覆盖。
- ISO／BDMV 与光盘会话会先过滤软件托管的选项（`--playlist`、`--bluray-device`、`--cache*`、`--demuxer*`、`--http-header-fields` 等），这些行在光盘播放中不生效。

## 六、常用示例

每段代码块中的内容都要**一行写进「启动参数」输入框**。

### 1. Anime4K 超分只给动漫

以下是我实际使用的一项组合超分参数：

```text
--glsl-shaders=~~/shaders/Anime4K/Anime4K_Clamp_Highlights.glsl;~~/shaders/Anime4K/Anime4K_Restore_CNN_Soft_M.glsl;~~/shaders/Anime4K/Anime4K_Upscale_CNN_x2_M.glsl;~~/shaders/Anime4K/Anime4K_AutoDownscalePre_x2.glsl;~~/shaders/Anime4K/Anime4K_AutoDownscalePre_x4.glsl;~~/shaders/Anime4K/Anime4K_Upscale_CNN_x2_S.glsl
```

- 分号分隔、不需要引号；`~~/` 指 mpv 的配置目录（便携版为 `portable_config`）。
- 建议只开「动漫注入」。若同时开「全部注入」，真人影片也会被超分。
- 若 `mpv.conf` 里的条件配置组（`profile-cond`）也写了 `glsl-shaders`，条件命中时会覆盖命令行，这属于 mpv 自身规则。

### 2. 启用 mpv.conf 里已有的动画配置组

```text
--profile=Anime4K
```

适合已经在 `mpv.conf` 写好 `[Anime4K]` 等配置组、只想在动漫上启用的情况。

### 3. 剧集：字幕位置与字号

```text
--sub-pos=95
```

```text
--sub-font-size=46
```

长剧集连续观看时更省眼，电影保持默认。

注意：字号设置命令可能对ASS无效，可以另起一行加上`--sub-ass-override=force`让字体修改强制生效。

### 4. 电影：运动补偿

```text
--video-sync=display-resample --interpolation=yes
```

真人电影常用；动画开启后可能产生果冻感，因此配合「电影注入」使用。

### 5. 电影：HDR 显示器色调映射

```text
--hdr-compute-peak=yes
```

```text
--target-peak=auto
```

### 6. 动漫：去色带

```text
--deband=yes --deband-iterations=4 --deband-grain=24
```

动画大面积平涂容易出现色带，真人电影通常不需要。

### 7. 全部注入：统一音量上限

```text
--volume=80 --volume-max=130
```

### 8. 剧集：自动跳过片头前若干秒

```text
--start=90
```

注意：`--start` 同时会被续播逻辑使用，存在续播进度时以续播位置为准；不需要时删掉此行。

## 七、用 Anime4K 实测（Windows + MPV）

1. 「设置 → 播放 → 外部播放器」中把可执行文件路径设为便携版 mpv，例如 `D:\MPV_Player\mpv.exe`。
2. 在「启动参数（每行一个）」中追加第六节第 1 条的那一行。
3. 保持「全部注入」开启，播放任意影片，确认画面已启用超分（线条更锐利）。
4. 关闭「全部注入」，只开启「动漫注入」，分别播放一部动漫和一部真人电影：动漫应有超分，真人电影没有。
5. 需要确认参数真的传给了播放器时，在 PowerShell 中查看命令行：

```powershell
Get-CimInstance Win32_Process -Filter "name='mpv.exe'" | Select-Object -ExpandProperty CommandLine
```

输出中出现 `--glsl-shaders=` 即表示已注入。

## 八、常见问题

**开关点不动？**
「全部注入」开启时另外三个开关刻意变灰，先关闭「全部注入」。

**动漫条目没有注入？**
按顺序检查：该资源是否已收录进影视库并完成刮削（作品详情能看到类型）；播放的是不是音乐或非媒体文件；「动漫注入」是否已开启且「全部注入」已关闭。元数据缺失时按设计不注入。

**真人电影也被注入了？**
说明命中的是「全部注入」或「电影注入」。若只想要动漫，关闭「全部注入」只开「动漫注入」。

**为什么某部动画没被识别成动漫？**
该作品的类型里没有动画类条目（例如 TMDB 资料只标了「剧情」），可在影视库中刷新元数据后重试。

**切集后参数变了或没变？**
参数在播放进程启动时固定。同一会话内切集、换季沿用起播判定；跨作品的自定义播放列表按起播条目判定。

**改了开关不生效？**
保存设置后需要重新起播（已在播放的进程不会改写参数）。

**升级后原来的播放行为变了吗？**
没有。「全部注入」默认开启，等于旧行为；新增的三个分类开关默认关闭。

**加了命令之后播放器没法启动？**

可能是命令输入有误或者格式不规范导致 mpv 在启动阶段发生报错。
