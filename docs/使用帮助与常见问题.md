# StreamPath 使用帮助与常见问题

本页适用于 Windows 版 StreamPath。遇到打不开媒体、匹配错作品或无法更新时，可以先按现象查找对应问题。

## 首次使用与界面

### 问：为什么我的界面和 GitHub 首页截图不一样？

答：截图拍摄于当时的版本。作者偶尔会偷个懒，截图更新可能赶不上软件更新 🙂。按钮位置、菜单名称和功能入口以你安装的版本为准。可以在「设置 → 常规 → 软件更新」查看当前版本。同时也可能是软件的默认设置造成的，可以前在「设置 → 界面」中进行自定义调整

### 问：我已经更新了 MPV，为什么 StreamPath 还在用旧版本？

答：如果电脑里有多份 MPV，StreamPath 可能仍指向旧目录。在「设置 → 播放 → 外部播放器」重新指定新目录中的 `mpv.exe` 并保存，然后结束当前播放并重新起播。

## 影视库与刮削

### 问：文件夹里能看到影片，为什么影视库里没有？

答：「文件夹」可以直接浏览来源。要把本地或网络存储中的影片收录到主影视库，请在「文件夹 → 影视库」添加相应的电影或剧集目录，启用该目录，再执行「手动扫描」。遇到个别子目录始终缺失时，检查「设置 → 影视库 → 影视库偏好」里的「屏蔽文件夹名称」。浏览 Jellyfin 或 Emby 的影片时，从影视库顶部选择对应的服务器。

### 问：怎样给媒体文件命名，才能提高刮削准确度？

答：剧集至少保留**作品名、作品最早发布年份和季集号**。年份使用作品的首播年份，即使后几季在其他年份播出也保持一致。电影使用片名和最早上映年份即可。

- 剧集第一季第一集可命名为 `进击的巨人.2013.S01E01.mkv`。
- 电影可命名为 `星际穿越.2014.mkv`。

如果资源包有简称、版本号或画质标签，把这些信息放在片名、年份和季集号之后。遇到同名作品时，尤其要核对年份和媒体类型。

### 问：扫描完成了，为什么只有文件名，没有海报和简介？

答：扫描负责发现媒体。要补齐在线资料，请在影视库设置中保存并验证 TMDB 的 **Read Access Token**，确认当前网络可连接 TMDB，再运行刮削。对于已准备本地 NFO 的目录，可以在「编辑影视目录」中检查元数据读取选项；只有媒体文件时也可以继续播放。

### 问：为什么同一季换了版本以后，有几集不见了？

答：详情页按所选版本显示分集，某个版本缺少的集数会隐藏。打开剧集详情，在季列表右侧换成包含这些集数的版本，或者检查资源文件的季集号和版本归属。各版本各自保留播放进度。

## 视频播放与离线缓存

### 问：为什么 MPV 的列表只显示当前集和下一集？

答：使用隐式播放列表时，StreamPath 持有完整队列，MPV 默认只挂入当前集和下一集，后续条目随播放推进逐步加入。可以在「设置 → 播放 → 播放行为」调整「隐式播放列表集数上限」。调大上限会提前准备更多条目，也会增加网络和缓存开销。

### 问：为什么能看到 STRM 文件，点击后却播不了？

答：STRM 文件保存的是媒体地址。能浏览目录，只说明 StreamPath 能读取这个文件。请检查地址是否已过期，以及播放器能否访问目标媒体。使用 OpenList 时，可以先检查对应存储是否启用了「启用签名」，再重新起播。

### 问：为什么离线缓存已经下载了一部分，断网后还是播不了？

答：要等所选版本及必要附件下载完成，才能使用这一版本的完整离线缓存。先到「设置 → 缓存 → 视频离线缓存」查看任务状态，并确认缓存的版本与实际选播版本一致。缓存 ISO 会下载完整镜像，缓存 BDMV 会下载整盘目录，因此单集来自光盘时，所需空间也可能接近整盘。 [视频离线缓存](视频离线缓存.md)

## 光盘播放与外挂字幕

### 问：为什么同一张光盘在本地能播，放进网盘就卡顿或无法起播？

答：**⚠️ 光盘播放仍是实验性功能。** 在线光盘播放既需要持续供数，也会频繁随机读取镜像或目录中的不同位置。普通视频能流畅播放、一次连续测速很快，都无法说明网盘能稳定应付这类读取。网盘的限速、请求频率限制、随机读取支持和响应延迟通常由服务商决定，可能导致起播失败、卡顿或频繁缓冲。

体积较小的普通蓝光和 DVD 通常相对容易播放，仍会受线路和服务商限制。大体积 UHD 蓝光在网盘上的流畅播放仍是未解决项。推荐本地播放，或使用自己可控、没有人为限速、带宽充足且支持稳定随机读取的服务器。如果来源支持完整离线缓存，可以缓存整盘后再播放。

### 问：想使用蓝光菜单和光盘外挂字幕、字体，应安装哪个 MPV？

答：MPV **0.42.0 正式版已发布**。要完整体验 StreamPath 的 Blu-ray BDMV／ISO 菜单及光盘外挂字幕、字体功能，建议使用官方 Windows **x86_64（full）** 构建。解压后在「设置 → 播放 → 外部播放器」指向新目录中的 `mpv.exe`，再重新起播。远程蓝光菜单还需要安装 StreamPath 随附的 WinFsp。 [MPV v0.42.0 官方发布页](https://github.com/mpv-player/mpv/releases/tag/v0.42.0)

### 问：为什么 DVD ISO 只有标题列表，或者某张蓝光盘进不了菜单？

答：StreamPath 的 DVD ISO 入口按标题列表播放，蓝光 ISO／BDMV 才提供可选的原生 HDMV／BD-J 菜单。蓝光能否进入菜单还取决于 MPV 构建和盘片兼容性。先确认使用的是未加密光盘及支持菜单的播放器构建。菜单进不去时，可以改用标题模式选正片。StreamPath 支持播放未加密内容，受 CSS、AACS 或 BD+ 保护的光盘需要由其他支持该保护机制的播放器处理。

### 问：外挂字幕明明在硬盘上，为什么没有显示，或者字体被替换了？

答：先在「设置 → 播放 → 播放行为」开启「自动注入匹配的外挂字幕、外挂字体与 LRC」。字幕轨已加入但尚未选中时，可在 MPV 手动选择，也可开启「自动选择已注入的外挂字幕与 LRC」。

光盘外挂支持 `.ass`、`.ssa`、`.srt`。ISO 和 BDMV 有各自的摆放位置和标题编号匹配规则。ASS／SSA 需要的字体请放进指定的 `fonts` 目录，把字体文件直接放在该目录下。仅有字体而缺少匹配的 ASS／SSA 字幕时，光盘播放不会准备该字体目录。 [ISO 与 BDMV 外挂字幕命名与使用](ISO与BDMV外挂字幕命名与使用.md)

## 软件更新与数据

### 问：为什么「检查更新」失败，或者能看到新版本却下载不了？

答：更新需要连通 GitHub 的 Release 查询接口和下载地址。页面能打开时，安装包下载仍可能因线路或重定向而失败。中国大陆的网络连接情况因运营商和线路而异，自动更新可能不稳定。可以稍后在「设置 → 常规 → 软件更新」重试，或者在网络可用时从项目 Releases 手动获取对应的安装包（`.setup.exe`）或便携包（`.portable.zip`）。 [StreamPath Releases](https://github.com/Yufuxk/StreamPath-OpenList-MPV-Linker/releases)

旧版本可能需要先手动升级。若正式发布缺少自动更新清单或与你的安装类型匹配的文件，也需要手动更新。安全更新提示校验失败时，请重新下载官方发布文件。

### 问：换了一个目录或从便携版改用安装版，为什么资料看起来都没了？

答：便携版从程序同级的 `stream_path_data/` 读取资料，安装版使用 `%LOCALAPPDATA%\StreamPath\stream_path_data\`。新目录或另一种安装方式会读取自己的数据。先确认原副本及其数据目录仍在，原位升级便携版前请保留该目录。要迁移影视库资料，可以使用影视库设置中的 ZIP 导出与导入。影视库 ZIP 不含连接密码和下载的视频，换机时请另外保留这些信息及文件。 [安装与软件更新](../README.md#安装与软件更新)
