# StreamPath

StreamPath 是面向 Windows 的便携 WebDAV 与本地媒体浏览器。它负责浏览目录、解析
STRM、匹配外挂字幕与字体、启动 MPV 等外部播放器（目前主要面向 MPV 播放器），并将播放进度、缓存策略和会话状态
保存在程序目录下的 `stream_path_data/`。

当前版本按功能能力支持 OpenList/AList：已核验的 OpenList v4.0.0、v4.1.4、v4.2.5
支持增强索引与存储恢复；AList v3.0.1～v3.63.0 按端点矩阵分级支持，未知版本不会被
乐观宣称为完整兼容。MPV 已实测 0.34.0 与多个 0.41+ 构建。架构、协议与技术细节见
[PROJECT.md](PROJECT.md)。

## 主要功能

- 使用 WebDAV `PROPFIND` 浏览目录，支持中文长路径、自然排序和目录缓存。
- 支持保存多个服务器档案，并在“文件夹管理”中从已保存档案挂载多个 WebDAV 服务器；
  挂载列表重启后保留。档案之间的目录缓存和播放进度按来源隔离。
- 侧边栏集中提供网络文件夹、本地文件夹、文件夹管理、媒体中心、搜索和设置入口；
  可固定显示，也可自动隐藏并在鼠标移入左边缘时展开。
- 本地存储支持多个可启用/停用的根目录，可输入
  绝对路径，也可打开 Windows 原生目录选择器添加。
- 播放视频、音频和同源 STRM；视频自动切集，音频自动生成带曲名的 M3U8。
- 本地 ISO/BDMV 可显式选择 MPV 蓝光菜单或主标题模式。
- WebDAV Blu-ray ISO 远程流式播放：支持 Title 选择排序和 ISO 独立续播，不需要
  驱动、管理员权限或完整下载；可选 HDMV 蓝光菜单（测试功能）。
- 音频支持 MP3、FLAC、WAV、M4A/M4B、AAC、OGG/Opus、WMA、APE、
  ALAC、AIFF、MKA、AC3/EAC3、DTS、DSF/DFF、WV、TAK、TTA、AAX 等
  常见格式，实际解码能力由当前 MPV 构建决定。
- 音频自动注入同目录同名 LRC 歌词；封面优先使用内嵌图片，外挂封面按同名图片
  及 `cover`、`folder` 等标准名称匹配。
- 按同目录、同文件名规则匹配字幕；WebDAV 视频可自动加载同级已识别字体目录中的字体；
  “自动注入”和“自动选择”可分别关闭。普通 WebDAV 视频启动时显示播放列表、字幕和字体准备进度。
- 使用 SQLite、MPV watch_later 和逐媒体日志同步续播进度；最多同时管理两个互不
  干扰的播放会话。
- 浏览页支持列表和平铺浏览、时间/体积/名称排序和鼠标滚轮；本地文件夹显示递归总大小。
  侧边栏媒体中心按视频、音频和 ISO 分栏展示收藏、继续播放、最近播放与最近目录。
- 侧边栏搜索覆盖所有已挂载的文件夹和文件；普通 WebDAV 和本地来源可建立客户端索引，
  OpenList/AList 优先使用服务端索引。
- 设置页分为服务器、播放、媒体中心、缓存、诊断、界面和基础设置分页；界面可在
  默认样式与 Windows Acrylic/Mica 系统材质之间切换。设置 → 界面 → 软件字体可展开选择
  Windows 已安装字体，保存后应用到软件界面；选择“系统默认”使用 Segoe UI 系列。
  支持简体中文、繁体中文、日文和英文。
- 可选的 OpenList/AList 自动恢复：仅在 MPV 明确报告播放错误时尝试重新拉起播放；
  默认关闭。

## 运行要求

- Windows 10 或 Windows 11 x64。
- 网络存储需要一个可访问的 WebDAV 地址和用户名（推荐为 OpenList）；服务器未设置
  密码时密码框留空。
- 本地存储可单独使用，不要求配置 WebDAV；视频、音频和本地 ISO 菜单需要配置可执行的 MPV 路径（其他视频/音频播放器仍可按模板使用）。WebDAV ISO 播放由随软件发布的 Bridge 完成，不依赖 MPV 内置 libbluray。
- 播放 STRM 文件时建议在 OpenList 的 STRM 存储设置中开启 `启用签名` 选项。建议在
  MPV 配置文件中完全注释或删除 IPC 的配置代码，保证软件的 IPC 功能能够正常运行
  （如 `input-ipc-server=` 字样）。

## 快速使用

1. 启动 `streampath.exe`。
2. 选择已有服务器档案，或填写档案名称、WebDAV 地址和用户名新建档案；密码按服务器
   实际配置填写或留空。
3. 在侧边栏打开“文件夹管理”，从已保存档案添加服务器，或添加本地文件夹。
4. 连接成功后进入目录，单击视频、音频或有效 STRM 播放；WebDAV `.iso` 进入
   Title/MPLS 选择流程，本地 `.iso`/BDMV 可选择蓝光菜单或主标题模式。
5. 首次使用前在设置页确认播放器可执行文件路径和参数模板。
6. 使用侧边栏“搜索”查找全部已挂载来源；点击结果会打开真实目录并定位条目。
   侧边栏“媒体中心”可筛选来源，查看收藏、继续播放与长期历史。
7. 网络与本地分类会保留各挂载上次成功打开的目录；“设置 → 界面 → 上次浏览目录”
   可选择仅在本次运行期间保留，或跨软件重启保留。

## 本地存储和蓝光菜单

“本地文件夹”显示已挂载的本地根目录。添加时可以直接填写 Windows 绝对路径，也可以
点击文件夹按钮打开系统目录选择器；目录浏览只在进入时读取当前层级，遇到越界路径或
已删除目录时会明确提示。Windows 本地列表遵循文件的隐藏和系统属性，不显示对应条目。
本地目录的大小包含其中所有子文件夹的文件大小；网络文件夹不显示目录总大小。
在“设置 → 媒体中心”开启“本地挂载文件夹共享”后，本地存储列表底部汇总已启用
根目录的继续播放栏；“网络存储共享”则在网络存储列表底部汇总已挂载服务器的继续播放栏。

本地视频和音频直接交给配置的播放器。打开 ISO 或 BDMV 文件夹时可选择"蓝光菜单播放"
或"主标题模式"；BDMV 请选择包含 `BDMV`/`CERTIFICATE` 的光盘根目录。ISO 播放记录会
保存文件快照和可用的 Title 信息，只在进入稳定 Title 后显示续播，文件被替换后不会
沿用旧位置。

## WebDAV Blu-ray ISO / BDMV 远程播放系统

远程 BDMV 文件夹播放：进入包含 `BDMV` 的光盘根目录，或进入 `BDMV` 文件夹，点击“选择播放方式”。播放列表模式支持选择、排序 Title；蓝光菜单模式使用 WinFsp 和配置好的 MPV。目录需保留完整蓝光结构，服务器需支持 Range 随机读取及资源版本校验。媒体按需读取，无需完整下载光盘。

BDMV 播放记录沿用媒体中心 ISO 分栏和续播入口。外挂字幕可放在光盘根目录及已有约定的字幕子目录中，也支持根目录上一级带光盘名前缀的字幕文件；绑定、字体和自动选择规则与 ISO 相同。菜单外挂字幕可能因 MPV 时间轴兼容性而不同步。

点击 `.iso` 后，StreamPath 启动随软件发布的 Bridge 对远端镜像做严格探测，确认服务器
支持随机读取后，按 Title/MPLS 解析光盘结构并提供 Title 选择；播放为流式随机读取，
不会下载完整 ISO。ISO 是独立于普通视频的媒体类型：媒体中心提供 ISO 分栏，按
"第 N/M 集 · 已播放时间"显示多 Title 播放进度，并支持 ISO 独立续播。

可选 HDMV 蓝光菜单（测试功能）通过 WinFsp 只读虚拟 ISO 复用用户现有的本地菜单
MPV；缺少运行时时提供随包安装入口。设置 → 播放 → “WebDAV 蓝光菜单进度”默认独立，仅保留上次光盘和目录；共享时记录正片进度供标题模式使用。两种设置下菜单都从头启动，更改对新会话生效。菜单导航下 MPV 的缓存条可能显示 0 秒，属正常
现象。播放时按 **Ctrl+Alt+i** 可开关独立的 ISO 前向缓存面板，查看连续已缓存 MiB 和估算时长；原生 i → 3 保留不变。估算需要几秒连续播放，切集、Seek 或进入菜单后会重新采样，不代表保证可播放的秒数。面板语言跟随启动会话时的应用语言。

当前支持 Windows x64、未加密 Blu-ray ISO 的 Title/MPLS 播放和可选 HDMV 菜单；
DVD ISO、AACS/BD+ 加密碟片、BD-J 和完整 ISO 磁盘缓存不在支持范围内。缓存、协议与
安全设计详见 [PROJECT.md](PROJECT.md)。

## 服务器档案与凭据

"设置 → 服务器"可以新建、编辑和删除服务器档案，并为每个档案设置登录后的默认目录。
已连接的档案必须先移除挂载或断开连接才能删除；登录页或设置页切换档案时会发起真实认证，
验证成功才保存为活动档案。
“文件夹管理”从已保存档案添加挂载，也可重试或移除；点击“网络文件夹”中的服务器进入浏览。“移除挂载”
只移除入口，保留档案和媒体记录。连接暂不可用时，挂载项仍保留，可点击重试。
“设置 → 媒体中心”的数据展示按钮可分别开启网络存储共享和本地挂载文件夹共享；
也可选各来源独立或本地与网络存储共享。新配置默认分别开启网络和本地共享。

密码与 OpenList/AList Token 默认保存在当前 Windows 用户的凭据管理器中，配置文件
只保存非敏感字段。需要完整复制便携数据时，可以明确选择"便携明文"；此模式会把密码
和 Token 直接写入配置 JSON，必须自行保护数据目录。

配置具备版本化迁移与自动备份能力：损坏时启动会回退最近有效备份，跨版本升级前会
先生成独立备份。版本细节与迁移规则见 [PROJECT.md](PROJECT.md)。

## 诊断中心

"设置 → 诊断"可以分别检查 WebDAV、播放器路径、MPV IPC、OpenList/AList 公开 API、
数据目录写入、视频/音频 SQLite、Hive 目录缓存以及配置迁移状态。检查结果彼此独立，
某一项失败不会掩盖其他检查。

"导出脱敏诊断包"会生成一个 JSON 文件，不包含用户名、密码、Token 和完整服务器
地址（只保留来源和路径摘要）。发送文件前仍建议按普通隐私文件自行复核。

"非破坏性维护数据库"仅在播放器全部关闭时可用，执行完整性检查、一致性备份、
`REINDEX` 与 `ANALYZE`，不会删除播放进度；若完整性检查已报告损坏会停止自动维护。

## 搜索与媒体中心

本地浏览页的当前目录搜索按文件名执行不区分大小写的包含匹配，中文可直接输入；关闭搜索后恢复
原目录的列表和滚动位置。搜索输入框支持 `Win+V` 剪贴板历史。

WebDAV 浏览页搜索框默认选择“全部索引”，可切回当前目录。侧边栏“搜索”首次打开时
后台建立客户端索引，之后可手动刷新；索引状态按来源显示。普通 WebDAV 只读取目录列表，
不读取文件正文。OpenList/AList 优先使用服务端索引。点击搜索结果会重新读取真实目录并
定位条目，已失效的条目会提示刷新索引，不会直接播放。

"设置 → 服务器 → OpenList/AList 索引"可以手动立即更新，或开启定时更新（默认关闭，
间隔最短 5 分钟、最长 7 天）。更新使用管理员 Token 或管理员账号密码，搜索仍使用
普通用户权限。使用前需先在 OpenList/AList 中启用数据库索引和增量自动更新能力。

目录、视频、STRM 和音频条目右侧可以切换收藏；外部播放器成功启动后才会写入最近
播放。同一批播放列表切集或切歌时原位更新同一条记录，不会为每一集新增位置。媒体中心
保持打开时会跟随播放进度自动刷新，无需退出页面。

"设置 → 媒体中心"可以调整收藏、继续播放、最近播放和最近目录的数量限制，并提供
分项一键清理：清空继续播放只隐藏续播入口，不删除底层进度；清空最近播放会同时移除
派生的继续播放入口，但保留 SQLite 和 watch_later 中的实际进度。

### 数据共享与本地蓝光续播

在"设置 → 媒体中心 → 数据展示模式"可分别开启"网络存储共享"和"本地挂载文件夹共享"，
默认两项均开启；也可选择"各来源独立"或"本地与网络存储共享"。共享模式合并
媒体中心和底部播放栏并标注记录来源；
切回独立模式后按原来源分组，历史和进度不会被搬移或删除。

手动删除本地蓝光底栏只关闭对应播放器并隐藏该底栏，未播完内容仍可从媒体中心继续
播放。

## 视频外挂字幕与字体

设置 → 播放 → “特典播放列表”可选“关闭特典递归”“仅 OVA 与番外”“全部特典视频”，
默认“仅 OVA 与番外”。点击普通视频时，当前目录视频排在前面，识别到的特典目录视频按
文件名自然顺序接在后面。“扫描视频文件夹内的特典目录”默认开启；“扫描与视频文件夹同级的特典目录”
默认关闭。两个开关可单独或同时开启。例如正片在作品目录下的分集文件夹中，而
`Specials` 与分集文件夹同级时，可开启后者。两项都关闭时不加入特典；只进入识别到的
特典目录及其内部子目录，不遍历其他普通文件夹。
识别名称包括 `Extras`、`Specials`、`Bonus`、`OVA`、`OAD`、`SP`、`NCOP`、
`PV`、`特典`、`番外`、`番外篇`、`特别篇` 等。“仅 OVA 与番外”只加入 OVA、OAV、
OAD 或番外目录及带这些标记的视频；`ONA` 归入“全部特典视频”。本地和 WebDAV 均适用，
ISO、BDMV 和音频仍使用各自的播放入口。部分目录读取失败或达到扫描上限时，已找到的
视频仍可播放，并会提示列表可能不完整。

“自动切季”默认开启，可在“设置 → 播放”手动关闭；“允许跳过缺失季”默认关闭。
播放当前季的整份列表（包括已加入的特典）后，程序会按视频文件名中的 `S02`、`S02E01`、
“第二季”等标记确认同级文件夹中的下一季，并在同一 MPV 进程中继续播放。文件夹名可以是
`2`、`2.《剧名》` 或“第二季”等，仅用于辅助判断。默认只接连续季；开启跳季后可接最近的
更高季。底栏与媒体中心会随实际播放的新季更新，本地和 WebDAV 普通视频均适用。
在视频继续播放栏点击“跳过本季”并确认，可直接从下一季首集播放；正在运行的 MPV
保持同一进程。找不到符合跳季设置的下一季时会提示，当前季播放列表保持不变。

外挂字幕按每集视频所在目录的同名文件匹配。启用“自动注入匹配的外挂字幕、外挂字体与
LRC”后，本地和 WebDAV 视频会从该集目录的直属子目录中精确识别一个字体
目录，常见名称包括 `Font`、`Fonts`、`字体`、`字體`、`字体文件`、`字体包`、`字幕字体`、
`Subtitle Fonts`、`Sub Fonts`、`ASS Fonts`、`字体备份`、`フォント` 和 `폰트`。识别忽略
大小写、空格及常见连接符；若同时存在多个候选，优先字幕专用名称，其次常规名称、字体
文件/字体包名称，最后才使用备份名称。

字体目录只收取直属的 `.ttf`、`.otf`、`.ttc`、`.otc` 文件。普通 WebDAV 视频启动时，
准备弹窗会显示当前步骤；下载字体时会显示文件名、文件数和已接收字节。设置 → 播放 →
“缓存 WebDAV 外挂字体”默认开启：字体保存在软件缓存目录中，同一来源的视频继续播放会话
可直接复用；对应会话从底栏与媒体中心继续播放中都消失后清理。关闭后，字体下载到本次
播放独立的临时目录，并在会话结束后清理。本地字体直接使用本地路径。“特典字体串用”默认
关闭，开启后仅当某集没有同目录可用字体时使用本次播放列表根目录的字体；自动注入关闭时
此选项不生效。MPV 0.36 及以上支持字体目录选项；更旧的 MPV 会跳过字体增强继续播放。

## 蓝光外挂字幕

WebDAV 与本地的 Blu-ray ISO、BDMV 文件夹均支持 `.ass`、`.ssa`、`.srt` 外挂字幕，沿用“自动注入匹配的外挂字幕、外挂字体与 LRC”和自动选择字幕开关。BDMV 光盘根目录通常可见 `BDMV`、`CERTIFICATE`，按现有“检测到 Blu-ray BDMV”入口识别。

1. ISO 字幕放在 ISO 同目录或该目录下的 `Subtitles`、`Subtitle`、`Subs`、`Sub`、`字幕` 文件夹中；BDMV 字幕放在光盘根目录或这些同名子目录中。只读取直属文件。BDMV 父目录中以光盘目录名为前缀的字幕也可作为候选。
2. 已知节目 MPLS 时，可命名为 `电影名.mpls00003.zh.ass`（ISO 为 `电影名.iso`，BDMV 为光盘目录名）。单张光盘范围内也可用 `mpls00003.zh.ass`。普通字幕名称仍可按正文结束时间、节目时长、集数、光盘名称、语言和格式评分；`01.ass`、`EP02.chs.ass`、`S01E03.ass`、`第04话.ass` 可参与集数评分。
3. WebDAV Title 选择窗口中的“蓝光外挂字幕”，以及播放后底栏的字幕按钮，可按 `00003.mpls` 等节目保存、禁用或恢复自动建议。菜单播放与本地主标题播放通过底栏设置；绑定会在以后打开同一来源的同一光盘时保留。
4. ASS/SSA 字体可放在 ISO 同目录或 BDMV 光盘根目录下的 `Fonts`、`字体` 等受支持字体目录中。只加载所选目录的直属字体；播放后新增字体应重新打开光盘。

无需先打开字幕面板，播放列表、本地主标题及蓝光菜单均会自动应用最高分候选。手动绑定或“不使用外挂字幕”优先，恢复自动建议后重新采用评分结果。集数按完整节目表中不少于 5 分钟的节目去重后按 MPLS 升序推测，不受本次勾选、拖动顺序影响；跨碟集数、不同剪辑版或近似时长可能匹配错误，可在面板纠正。自动评分需要读取当前范围内的候选字幕，会增加少量启动准备时间。

切换节目时自动切换字幕，进入菜单时暂停自动外挂；不会删除内封 PGS 或手动加入的字幕。自动选择关闭时只增加可选轨道。MPV 无法确认当前节目、字幕准备失败或绑定文件异常时，视频继续播放，面板显示提示。光盘信息变化后旧绑定暂停应用，需要重新确认。

蓝光菜单外挂字幕可能受 MPV 时间轴兼容性影响而不同步；加载字幕不会自动改变播放位置。

## 音频播放

单击音频后，StreamPath 使用当前目录的稳定自然顺序创建 UTF-8 M3U8，点击项作为播放
起点，每个条目使用服务器文件名作为曲名。临时排序、隐藏后缀和搜索结果不会改变播放
列表顺序。

音频伴随文件规则：

- 歌词只接受音频同目录、主文件名完全相同的 `.lrc` 文件，服从"自动注入"和
  "自动选择"开关；
- 内嵌封面由 MPV 原生识别并保持最高优先级；外挂封面先匹配同名图片，再匹配
  `cover`、`folder`、`front`、`album` 等标准名称；
- 歌词和封面按播放列表位置逐曲目注入，切歌时不会串到其他曲目。

“设置 → 播放 → 音频歌词”中的“MPV 动态歌词”默认开启。同名 LRC 会在 MPV 窗口中按行滚动；歌词含
逐字或逐词时间戳时同步高亮，同一时间点的译文、罗马音等附加行按文件顺序显示。普通
逐行 LRC 只显示逐行效果。主行与辅助行的间距按每句实际行数调整；此设置卡片还可指定
歌词字体、描边粗细和整体透明度。动态歌词依赖“自动注入匹配的外挂字幕、外挂字体
与 LRC”；关闭“自动选择”时仍需在 MPV 中手动选择歌词轨道。无封面音频也会打开 MPV
窗口显示歌词；无法解析的文件沿用原 LRC 显示。歌词文字与时间只来自现有 LRC 文件。

音频下边栏支持显示当前曲名、暂停、继续、关闭与应用重启后的"继续播放"。自然播放
完成会清除旧进度，明确回到 0 秒会覆盖旧进度，普通退出使用 MPV 的精确最终位置。
音频不使用缓存控制与动态优化，完全采用 MPV 自身默认缓存机制。

## MPV 兼容性

StreamPath 已对 mpv 0.34.0 与多个 0.41+ 构建完成自动化实测，覆盖 Lua、named pipe
IPC、状态文件、进度日志、字幕、watch_later、远程 LRC 与封面等能力。外挂字体目录选项
从 MPV 0.36 起提供；旧版本会跳过该增强。实测版本清单与
复测方法见 [PROJECT.md](PROJECT.md)。

## OpenList/AList 自动恢复

设置页可填写后台地址和管理员 Token，或填写管理员账号、密码。推荐使用 Token；启用
2FA 的账号必须使用 Token。

恢复仅在 MPV 明确报告媒体读取错误、且原地址 Range 探测确认不可用时尝试：先重新
登录并刷新存储，再重新拉起播放。每个会话最多恢复 3 次；第三次仅支持本机、以标准
方式运行的 `openlist.exe` / `alist.exe`，通过服务自身优雅退出后重启，不会使用强制
杀进程。远程后台、反向代理、Docker 或 Windows 服务不会被自动重启。

“设置 → 服务器 → OpenList/AList 后台与自动恢复 → 本机服务重启目录”提供两种选择：

- 默认路径（默认）：以当前 Windows 用户目录，例如 `C:\Users\用户名`，作为重启工作目录。
- 安装路径：以当前已确认的 `openlist.exe` / `alist.exe` 所在目录作为重启工作目录。

StreamPath 成功连接服务后会在后台识别本机监听进程并记录 exe 路径，重启前重新核对。
路径记录保存在本次应用进程内，重开软件并连接后重新识别；目录模式随服务器档案保存。
两种模式均保留 `server --force-bin-dir` 参数，因此该选项只改变工作目录，不迁移服务数据。
目标目录不可用时取消重启，不先停止正在运行的服务。

恢复流程、端点语义与安全边界见 [PROJECT.md](PROJECT.md)。

## 数据目录

便携版数据位于程序同级 `stream_path_data/`，分为四个部分：

- `config/`：统一用户配置、缓存策略配置及持久目录位置记录，含自动备份；
- `library/`：收藏、最近目录和长期播放历史；
- `cache/`：目录缓存、全局搜索索引、播放进度数据库、MPV watch_later、ISO 目录与续播等运行时数据；
- `diagnostics/`：用户主动导出的脱敏诊断包。

完整文件清单与迁移规则见 [PROJECT.md](PROJECT.md)。

## 缓存过期配置

"设置 → 缓存 → 缓存过期时间"可以修改以下项目：

- 目录刷新间隔：默认 10 分钟，可设置 1～1440 分钟；
- 目录快照保留时间：默认 30 天，可设置 1～3650 天；
- 滚动位置保留时间：默认 30 分钟，可设置 1～1440 分钟；
- 续播记录保留时间：默认 365 天，可设置 1～3650 天，同时作用于视频/音频进度和
  MPV `watch_later`；
- 媒体元数据保留时间：默认 180 天，可设置 1～3650 天。

非法或越界的配置值会自动回退默认值或收敛到允许范围。缓存学习数据不参与自动过期，
只能通过"清理学习数据"按钮重置。

## 常见问题

- **空密码无法连接**：确认服务器确实允许该用户名使用空密码；失败会显示服务器或
  网络错误。
- **MPV 无法启动**：在设置页使用 `mpv.exe` 的完整路径，先在终端执行该文件的
  `--version`。
- **STRM 不显示或不可播放**：只接受非空、8192 字节以内且与 WebDAV 同源的目标；
  第三方直链会被拒绝。
- **OpenList 恢复失败**：检查后台根地址、Token 权限和 2FA；后台反向代理必须允许
  管理 API 且不能把管理员请求重定向到其他来源。
