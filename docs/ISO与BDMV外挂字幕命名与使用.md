# ISO 与 BDMV 外挂字幕命名与使用

本文说明 StreamPath 为本地／WebDAV 的 ISO 与 BDMV 光盘加载外挂字幕时的目录位置、文件命名、自动匹配规则和界面操作方式。普通视频的外挂字幕使用另一套同名匹配规则，不在本文范围。

## 1. 适用范围与前提

- 支持本地和 WebDAV 的 ISO 文件、BDMV 文件夹；普通视频、STRM 和音频不使用本文规则。
- 只接受 `.ass`、`.ssa`、`.srt` 三种文本字幕。`.vtt`、`.sub`、`.idx`、`.sup`（PGS）等不会作为蓝光外挂字幕加载；盘内封装的 PGS／内嵌字幕仍由蓝光菜单或 MPV 原生轨道提供，不受影响。
- 必须先在「设置 → 播放 → 播放行为」开启「自动注入匹配的外挂字幕、外挂字体与 LRC」。关闭时既不发现也不挂载蓝光外挂字幕。
- 「自动选择已注入的外挂字幕与 LRC」决定字幕轨道加入后是否自动选中；关闭时只加入轨道，保留播放器原有的字幕选择。
- 字幕与字体只从光盘所在位置及限定目录读取，不会联网搜索或自动下载。

## 2. 放在哪里

### 2.1 ISO

- 与 ISO 文件同一目录，例如 `电影.iso` + `电影.chs.ass`。
- 或同目录下的字幕子目录，目录名支持 `subtitles`、`subtitle`、`subs`、`sub`、`字幕`（不区分大小写），只读取一层，例如 `subtitles/电影.chs.ass`。
- 同一目录存在多张 ISO 时，字幕文件名必须以对应 ISO 的文件名为前缀，否则会被忽略。

### 2.2 BDMV 文件夹

- 光盘根目录内（与 `BDMV`、`CERTIFICATE` 同级），例如 `电影/电影.chs.ass`。
- 光盘根目录内的字幕子目录，例如 `电影/subtitles/01.ass`。
- 光盘根目录的上一级目录，例如 `电影/` 的同级放置 `电影.chs.ass`。这一层必须以光盘文件夹名作为前缀，否则不参与匹配。
- 光盘根目录内部的字幕可以省略前缀，但带前缀同样有效，且优先级更高。

### 2.3 字体目录

ASS／SSA 字幕用到自定义字体时，在 ISO 文件所在目录（BDMV 为光盘根目录内）新建字体目录，把字体文件直接放在其中：

- 目录名支持 `fonts`、`font`、`字幕字体`、`字幕字体包`、`字幕字库`、`subfonts`、`assfonts`、`字体`、`字體`、`フォント`、`폰트` 等常见写法（忽略空格与标点，不区分大小写）。
- 字体目录与 ISO／光盘根目录同级，不能放进 `subtitles` 这类字幕子目录里。
- 只读取该目录的直属字体文件，扩展名支持 `.ttf`、`.otf`、`.ttc`、`.otc`，不递归子目录。
- 仅当候选字幕中含 `.ass`／`.ssa` 时才准备字体。
- 同一光盘只使用匹配度最高的一个字体目录；字体数量与总量受会话预算限制，超出部分不会加载。

## 3. 命名规则

匹配时先把文件名转为小写、去掉扩展名，再按以下顺序提取「前缀」「MPLS 标记」「集数标记」「语言标记」。

### 3.1 前缀

前缀是 ISO 文件名去掉扩展名，或 BDMV 光盘文件夹名，不区分大小写。文件名满足以下任一形式即视为带前缀：

```
<前缀>
<前缀>.其余内容
<前缀> 其余内容
<前缀>-其余内容
<前缀>_其余内容
```

- 单 ISO 目录可以省略前缀（目录里只有一张 ISO 时）。
- BDMV 光盘根目录内部可以省略前缀；光盘上一级目录的字幕文件必须带前缀。
- 文件名中出现 `mpls` 却不是「前缀 + `MPLS00001`」形式时直接忽略，避免把打包工具残留文件误当字幕。

### 3.2 明确指定 MPLS（推荐用于多集／多标题光盘）

在文件名中写入五位 MPLS 编号，紧跟在前缀之后：

```
电影.MPLS00001.chs.ass
电影.MPLS00002.chs.ass
电影_MPLS00003.zh-Hans.srt
```

- 编号必须是五位，写 `MPLS1`、`MPLS01` 都无效。
- 该文件只用于对应 MPLS，不会再被其他标题使用。
- 单 ISO 目录或 BDMV 光盘根目录内也可以省略前缀，直接写 `MPLS00002.chs.ass`。
- 语言等其他标记只能写在 MPLS 编号之后；带 MPLS 时不再读取集数标记。`电影.chs.MPLS00002.ass` 这种写法不会被识别。

MPLS 编号可以在蓝光标题选择窗口、字幕窗口的标题行（显示为 `00002.mpls`）或光盘结构的 `BDMV/PLAYLIST` 目录中看到。

### 3.3 集数标记（没有 MPLS 标记时使用）

文件名前缀之后可以带集数标记，支持以下写法（可出现在语言标记前后，`[`、`]`、`.`、`_`、空格、`-` 都是合法分隔符）：

| 写法           | 示例                             |
| ------------ | ------------------------------ |
| 纯数字          | `电影.01.chs.ass`                |
| `E`／`EP` 加数字 | `电影.E01.ass`、`电影.EP2.chs.srt`  |
| 季集编号         | `电影.S01E03.chs.ass`            |
| 中文集号         | `电影.第01集.ass`、`电影.03话.chs.ass` |

集数编号按「MPLS 编号升序、时长不少于 5 分钟的标题」从 1 开始计数。例如一张盘的主标题为 `00001`、两集正片为 `00002`、`00003`，短于 5 分钟的预告片不参与编号，则：

- `01`／`E01` 对应 `00001`；
- `02`／`E02` 对应 `00002`；
- `03`／`E03` 对应 `00003`。

同一张盘上一旦改动标题顺序或增删标题，集数编号会随之变化；这种情况建议改用 MPLS 标记。

### 3.4 语言标记

语言标记用于同类字幕的优先级排序，不影响是否命中：

| 优先级 | 常见写法                                 |
| --- | ------------------------------------ |
| 最高  | `chs`、`sc`、`zh-cn`、`zh-hans`、`简`、`簡` |
| 次之  | `cht`、`tc`、`zh-tw`、`zh-hant`、`繁`     |
| 再次  | `zh`、`chi`、`zho`、`中文`                |
| 日文  | `ja`、`jpn`、`jp`                      |
| 英文  | `en`、`eng`                           |
| 其他  | 其他标记或无标记，仅在无法命中更高优先级时使用              |

### 3.5 格式与「无标记」字幕

同一标题存在多个候选时，按 ASS > SSA > SRT 选择。没有 MPLS 或集数标记的字幕（如 `电影.chs.ass`）只能靠时长匹配：

- 读取字幕中最后一条时间轴作为字幕结束时间；
- 与当前标题时长比较，允许误差为「120 秒与视频时长 10% 中的较大值」；
- 字幕结束时间不能晚于视频时长 5 秒以上。

时长匹配适合电影正片；剧集盘多集时长接近时容易误配，建议加 `MPLS` 或集数标记。手动绑定不受这些限制，可兜底指定任意已发现字幕。

### 3.6 自动匹配优先级

自动建议按以下权重合计最高分：

| 条件              | 分值                         |
| --------------- | -------------------------- |
| 明确 MPLS 与当前标题一致 | +2000                      |
| 时长匹配            | 最高 +600（偏差越小分越高）           |
| 集数标记命中          | +200                       |
| 集数标记存在但不匹配      | −200                       |
| 语言标记            | 60 / 50 / 40 / 20 / 10 / 0 |
| 带前缀             | +40                        |
| 格式              | ASS +3、SSA +2、SRT +1       |

没有明确 MPLS 的候选，必须先满足时长匹配或集数命中的至少一项才会被采用；两者都不满足的字幕不会自动挂载，但可以在字幕窗口中手动选择。

## 4. 命名示例

电影（单 ISO，目录内只有一张 ISO）：

```
电影.iso
电影.chs.ass                 # 中文
电影.cht.ass                 # 繁体
电影.eng.srt                 # 英文
subtitles/电影.chs.ass       # 放在字幕子目录同样有效
fonts/思源黑体.ttf            # ASS 字体
```

剧集（多张 ISO，必须带前缀）：

```
Show.S01E01.iso
Show.S01E01.01.chs.ass       # 第 1 集（集数标记）
Show.S01E02.iso
Show.S01E02.MPLS00002.chs.ass # 明确 MPLS，最稳妥
```

BDMV 文件夹（光盘根目录内可省略前缀）：

```
电影 (2010)/
  BDMV/
  CERTIFICATE/
  电影 (2010).chs.ass        # 带前缀，优先级高于无前缀
  subtitles/01.chs.ass       # 字幕子目录
  fonts/STHeiti.ttc          # 字体目录
电影 (2010).chs.ass          # 放在光盘上一级目录时必须带盘名前缀
```

## 5. 使用步骤

1. 按第 2、3 节放好字幕（字体可选），刷新目录让 StreamPath 看到新文件。
2. 打开字幕窗口，任选一种入口：
   - 文件夹页右键 ISO／BDMV 条目，选择「蓝光外挂字幕」；
   - ISO 标题选择窗口中的「蓝光外挂字幕」按钮；
   - 播放中的底栏字幕按钮（提示为「蓝光外挂字幕」）。
3. 窗口会列出该光盘的每个标题（`00001.mpls` 形式）和时长，当前播放的标题带播放图标。每个标题一行下拉框：
   - 「自动建议：<文件名>」：使用按第 3 节规则计算的结果；
   - 「不使用外挂字幕」：该标题不加载外挂字幕；
   - 具体文件名：手动指定，覆盖自动建议并保存。
4. 「重试应用字幕」立即把当前选择推送到播放器，不必重启播放。
5. 关闭窗口后继续播放，选择会保留，下次打开同一光盘自动沿用。

手动绑定按「来源 + 光盘路径」区分，保存在 `stream_path_data/library/iso_subtitles/`。ISO 文件大小或修改时间变化、BDMV 结构 revision 变化时，旧绑定暂停应用并在窗口中提示「蓝光内容已变化，旧绑定暂停应用；请重新确认。」，确认后重新生效。

## 6. 自动挂载行为

- 标题模式：MPV 完成标题加载后识别节目并挂载字幕；普通 Seek 不会重复加载。
- 菜单模式：进入正片后才挂载字幕，菜单画面不显示外挂字幕；菜单切换标题后，外挂字幕的时间轴可能与画面不同步，这是当前已知限制。字幕挂载本身不执行 Seek、不修改 `sub-delay`，不会打断菜单章节落点。
- 自定义字幕文件只在 StreamPath 管理的会话内生效，不修改光盘内容、不写入用户 MPV 配置。

## 7. 匹配失败排查

按以下顺序检查：

1. 「设置 → 播放 → 播放行为」中的外挂字幕注入开关是否开启。
2. 字幕是否放在第 2 节的允许目录内，扩展名是否为 `.ass`／`.ssa`／`.srt`。
3. 多 ISO 目录或 BDMV 上一级目录的字幕是否带正确前缀（前缀为 ISO 文件名或光盘文件夹名）。
4. 文件名中的 `MPLS` 是否为五位编号，且紧跟在前缀之后。
5. 集数标记是否与实际标题顺序一致；标题数量变化后需要重新确认。
6. 无标记字幕的结束时间是否与标题时长相差过大（超过 120 秒或 10%）。
7. 窗口底部是否出现资源提示：
   - 「部分字幕或字体资源不可用，视频播放不受影响。」表示部分文件读取失败或超限；
   - 「字幕绑定文件不可用，原文件未覆盖」表示绑定文件损坏或不可写；
   - 「等待播放器提供节目列表。」表示光盘标题尚未解析完成，稍候重试；
   - 「当前节目尚不可识别或正在菜单中，自动外挂暂停。」表示当前画面不是可识别的正片。
8. 仍不匹配时，直接在窗口中手动指定该标题的字幕文件。

容量与预算限制（超出部分会被跳过而不是报错）：

| 项目        | 限制                                     |
| --------- | -------------------------------------- |
| 目录发现的候选字幕 | 最多扫描 64 个文件，合计读取 64 MiB                |
| 单个字幕文件    | 16 MiB                                 |
| 会话内字幕副本总量 | 64 MiB，最多 64 个不同字幕                     |
| 发现与准备时间   | 目录发现 10 秒；字幕与字体准备共享 10 秒预算             |
| 字体        | 仅读取匹配目录的直属 `.ttf`／`.otf`／`.ttc`／`.otc` |

## 8. 相关存储

- 绑定：`stream_path_data/library/iso_subtitles/<匿名光盘键>.json`，保存 version、revision 与各 MPLS 的字幕选择（`null` 表示不使用外挂字幕），不含媒体地址或凭据。
- 本地会话副本：`stream_path_data/cache/local_iso_subtitles/`，通用清缓存会保留该目录；播放退出后只回收进程身份明确失效的会话。
- 普通缓存清理不会删除绑定文件；需要重新自动匹配时在窗口中改回「自动建议」。
