# 安装器语言文件

简体中文、繁体中文消息文件来自 Inno Setup 官方源码仓库 `jrsoftware/issrc` 的 `is-6_2_2` 标签（commit `b30dac05db10c6e50391dd311e0e105cd9d05c06`），路径为 `Files/Languages/Unofficial/`。文件保留原译者署名与格式。

- [ChineseSimplified.isl 来源](https://github.com/jrsoftware/issrc/blob/b30dac05db10c6e50391dd311e0e105cd9d05c06/Files/Languages/Unofficial/ChineseSimplified.isl)
- [ChineseTraditional.isl 来源](https://github.com/jrsoftware/issrc/blob/b30dac05db10c6e50391dd311e0e105cd9d05c06/Files/Languages/Unofficial/ChineseTraditional.isl)

英文和日文复用 Inno Setup 编译器自带的语言文件。StreamPath 自定义提示集中在 `StreamPath.iss` 的 `[CustomMessages]` 中，覆盖同样四种语言。
